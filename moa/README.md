# 모아 (Moa) — 독립 페이지 통합 준비

모아는 일기·습관·사진·영상 기록을 위한 모바일 웹 서비스입니다.

## 현재 단계
- 기존 랜덤뽑기·Bible Reader·DEVICE CHECKUP과 독립된 제품 디렉터리로 관리
- 이 브랜치는 배포되지 않는 통합 준비 브랜치입니다.
- 기존 세 제품의 빌드/배포 설정을 변경하지 않았습니다.
- 기존 대화의 모아 v7 HTML 시제품은 아직 이 브랜치에 복사되지 않았습니다.
- 인증, 사용자별 데이터 격리, 클라우드 미디어 저장, 권한 검사 및 모바일 QA 완료 전 공개 배포 금지

## 통합 완료 조건
1. 검증된 v7 원본 소스 반영
2. 별도 빌드 및 독립 Cloudflare Pages 설정
3. 계정 인증 및 사용자별 접근 제어(RLS), 업로드 제한, 백업/복구 구현
4. 모바일 브라우저에서 작성·수정·삭제·달력·영상 자동 재생 검증
5. 출시 승인 및 배포 후 실서비스 확인

## 범위
기존 3개 제품은 변경하지 않음.
