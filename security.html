로컬 분석
수집한 연결·방화벽·LAN 증거는 이 도구가 서버로 업로드하지 않습니다.
중요: “위험 신호 있음”은 침입 성공 확정이 아닙니다. 반복 차단, 여러 포트 탐색, 민감 포트 접근, 인바운드 가능 현재 연결처럼 추가 확인이 필요한 증거를 우선 표시합니다.

실행은 3단계입니다

STEP 1ZIP 압축 풀기

다운로드한 폴더를 원하는 위치에 풉니다.

STEP 2RUN-CHECK.cmd 실행

더블클릭하면 Windows 증거를 읽기 전용으로 수집하고 결과를 검증합니다.

STEP 3결과 자동 확인

수집이 정상일 때만 로컬 분석 화면이 열리고 확인 우선순위를 보여줍니다.

이 도구가 하지 않는 것외부 호스트 스캔 · 방화벽 규칙 변경 · 프로세스 종료 · 수집 증거 서버 업로드를 하지 않습니다.
브라우저가 볼 수 없는 Windows 보안 증거는 사용자가 직접 실행한 로컬 도구에서만 읽습니다. 알 수 없는 신호를 침입이나 고장으로 단정하지 않습니다.
