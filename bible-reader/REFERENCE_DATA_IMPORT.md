# 1962 관주성경전서 개역한글판 — 원자료 수입 계획

## 목적

`관주성경전서 개역한글판`(1962)의 소제목·난하주·관주를 임의 생성 없이 원자료 그대로 디지털화하여 `annotations-data.js`에 연결한다.

## 확인된 권리 상태

- 저작물: `관주성경전서 개역한글판`
- 발행: 대한성서공회, 1962-05-10
- 저작재산권 보호기간: 2012-12-31 종료(대한성서공회 공식 안내)
- 사용 시 성명표시권·동일성유지권을 존중한다.
- 데이터화 과정에서 문구·기호·연결 구절을 임의 교정하지 않는다.

## 현재 원자료 상태

2026-09-01 공개 웹 조사 기준:
- Google Books에는 1962판 서지정보(1754쪽)가 있으나 eBook/전체 원문은 제공되지 않는다.
- 대한성서공회 및 서점에서는 종이 관주성경이 확인된다.
- 66권 전체 관주·소제목을 구조화한 공개 디지털 데이터셋은 확인하지 못했다.
- 따라서 다른 영어 성경 cross-reference, AI 생성 관주, 현대 개역개정 관주를 대체재로 넣지 않는다.

## 원자료 확보 후 처리 순서

1. 판본 확인
   - 표제/발행정보가 1962 관주 개역한글 계열인지 확인한다.
2. 페이지 이미지 또는 텍스트 확보
   - 원본 페이지와 페이지 번호를 보존한다.
3. 구조화
   - 소제목: `Book:Chapter -> verse/text/sourcePage`
   - 관주: `Book:Chapter:Verse -> marker/type/refs/text/sourcePage`
4. 자동 유효성 검사
   - 66권 책 코드
   - 장/절 범위
   - 잘못된 참조
   - 중복 항목
   - 빈 기호/참조
5. 표본 대조
   - 각 권 첫 장 + 무작위 표본을 원본 이미지와 대조한다.
6. 전수 구조 검사
   - 데이터 파싱 실패 0건 확인
7. UI 연결
   - 소제목은 해당 절 앞에 표시
   - 관주 기호는 본문 옆에 표시
   - 클릭 시 관주 내용/연결 구절 펼침
8. 출처 표시
   - `관주성경전서 개역한글판(1962) · 대한성서공회`
