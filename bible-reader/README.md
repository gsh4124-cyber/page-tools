# Bible Reader

PC에서 성경 본문 자체를 가장 편하게 읽기 위한 웹도구입니다.

- 기술 원본: `gsh4124-cyber/page-tools`의 `main / bible-reader/`
- 현재 기술상태: `PROJECT_STATUS.md`
- 상위 운영 원칙: 황제 Vault `직장/바이브코딩/_INDEX.md`
- 운영 주소: `https://bible-reader-1iz.pages.dev/`

## 로컬 작업 위치

로컬 checkout 경로는 환경별로 달라질 수 있으며 Canonical로 고정하지 않습니다. 작업할 때 `page-tools/main`의 실제 checkout 위치를 확인합니다.

과거 `gsh4124-cyber/bible-reader` 독립 repo와 옛 PC 절대경로는 현행 기술 원본으로 사용하지 않습니다.

## 핵심 방향

- PC에서 가장 편하게 읽는 성경
- 개역한글 1961 기본
- 책·장 이동, 검색, 주소 이동, 병렬 비교
- 본문 접근 자체는 유료화하지 않음
- 공개 서비스의 검색·광고·시장 상태는 실제 외부 증거와 운영 Gate를 기준으로 판단

연속으로 선택한 구절은 틈이나 중간 테두리 없이 하나의 선택 상자로 표시합니다. 떨어진 구절과 두 쪽 보기의 열 경계는 나누어 표시하며, 각 절을 다시 눌러 개별 해제할 수 있습니다.
선택한 절은 절 번호를 금색 배지로 표시하고 도구창 뒤의 본문은 비치지 않게 합니다. 선택 구절 메모창의 Tab은 창 안에서 이동하며, Esc로 닫으면 열었던 버튼으로 돌아갑니다.

## 타이핑 암기 시험

상단 더보기의 **타이핑 암기 시험**을 열거나 본문에서 여러 절을 선택한 뒤 같은 이름의 버튼을 누릅니다. 보기 방식은 **절 하나씩 보기**와 **장 한 번에 보기** 두 가지입니다. 기본은 현재 장 전체를 한 절씩 진행하며, **Enter로 답 확인 → 정답이면 다음 Enter로 다음 절**에 갑니다. 오답이면 수정·재확인할 때까지 같은 절에 머뭅니다. Shift+Enter는 줄바꿈이며, 한글 조합 확정이나 Enter를 길게 누르는 동작은 절을 넘기지 않습니다. 장 보기에서는 현재 장의 절을 함께 입력하고 모두 맞으면 다음 장으로 진행합니다.

접힌 **시험 범위**에서 현재 성경책·역본 안의 시작 장·절과 마지막 장·절을 정해 여러 장도 묶을 수 있습니다(예: 요한복음 3:16–4:3). 마지막 절까지 마치면 첫 답 확인 기준의 결과를 보여줍니다. **틀린 절만 재시험**은 그 시도의 첫 답에서 틀린 절만 빈 답안으로 시작하며, 재시험에서 다시 틀린 절만 반복할 수 있습니다. 모두 맞으면 이 버튼은 사라집니다. **전체 다시 시험**은 처음 선택한 전체 범위로 돌아갑니다. 읽기 위치는 바뀌지 않으며 장·절을 함께 표시해 답안이 섞이지 않습니다. 절 수·본문 전체 글자 수 제한 없이 시편 119편 1–176절도 지원합니다. 띄어쓰기·줄바꿈·문장부호·대소문자는 채점에서 제외하며 빠진 글자·다른 글자·추가 입력을 표시합니다. 답안은 저장·전송하지 않습니다.

시험 중 답 확인·범위 버튼은 아래 조작부에 남고 입력 부분만 스크롤됩니다. 본문은 시작 전 미리보기에서만 확인하며 시험 중 본문 보기와 힌트는 제공하지 않습니다. 장 보기의 입력칸은 작은 높이로 시작해 입력량에 맞춰 늘어나며 Tab으로 다음 절에 갑니다. 입력한 절 수와 진행 막대도 표시합니다. 두두캔의 공개 구절·장 암송 흐름을 직접 비교한 뒤 긴 장의 입력 밀도와 조작부 접근을 개선했습니다([참고 화면](https://dodocan.me/typing)).

시험 화면은 구절·입력칸·필수 조작만 표시합니다. 채점 기준·단축키·답안 처리 안내는 시작 화면의 접힌 도움말에 두며, 진행 중에는 중복 구절 제목과 긴 설명을 반복하지 않습니다. 절 보기의 Enter 동작은 버튼의 ↵ 표시와 접근성 안내로 제공합니다.

채점은 정답과 내 답을 나누지 않고 **한 본문**에 합쳐 표시합니다. 이어진 **오자(빨간 글자·대각선)**는 한 묶음으로 줄을 긋고, 해당 단어 위에 올바른 단어를 작게 표시합니다. **빠진 글자(파란 점선 밑줄)**는 원문 위치에, **더 쓴 글자(회색 취소선)**는 입력 위치에 표시합니다. 모두 맞았을 때도 정답 본문을 보여줍니다. 띄어쓰기·문장부호는 원문의 읽기 좋은 형태를 유지하며 밝은/어두운 화면 모두 적용합니다.

오답을 채점하면 첫 오답 입력칸으로 포커스와 스크롤을 이동합니다. 비교 결과는 해당 절 바로 아래에 표시하며, 다시 채점할 때는 남은 첫 오답으로 이동합니다. 수정 안내는 하단에 한 번만 표시합니다.

절 보기 입력칸도 작은 높이로 시작해 입력에 따라 늘어나고, 지우면 다시 줄어듭니다. 키보드가 표시될 때의 창 높이·위치는 `VisualViewport`의 실제 보이는 영역에 맞춥니다. 이 API가 없으면 일반 창 크기 변경으로 대체하며, 핀치 확대 시 강제로 창을 다시 맞추지 않습니다. 실물 키보드 확인은 브라우저 화면·모의 검사와 구분해 운영 기록에 남깁니다([MDN](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport), [Chrome 안내](https://developer.chrome.com/blog/viewport-resize-behavior/)).

휴대폰 대응은 특정 기종 전용이 아닙니다. 보이는 폭과 높이, 가로 회전, 안전 영역을 함께 반영합니다. 키보드 등으로 높이가 400px 미만이면 안내·진행 표시는 입력 스크롤 영역으로 옮기고 두 조작 버튼은 나란히 남겨 입력 공간을 확보합니다. 높이가 복구되면 기존 배치로 돌아갑니다. `tools/memory-quiz-mobile.mjs --local`은 Chromium·WebKit·Firefox에서 두 보기, 280–844px 폭, 가로 화면·큰 글씨·키보드 축소/복구·API 대체 동작을 검증합니다. WebKit 엔진과 화면 모의 검사를 iPhone Safari나 삼성 인터넷의 실물 전 기종 검사로 기록하지 않습니다([Playwright 검사 범위](https://playwright.dev/docs/emulation)).

- 시험 시작 화면에서 66권 중 성경책과 시작·마지막 장·절을 바로 고릅니다. 시험 범위는 읽던 위치와 독립적이며, 다른 책을 불러오지 못하면 이전 본문으로 시험을 시작하지 않습니다.

- 시험 중 이전·다음 절 버튼으로 자유롭게 이동하며 입력 초안은 해당 시험 동안 메모리에 유지됩니다. 장 보기에서는 이전·다음 장으로 이동합니다. Enter의 답 확인/정답 후 다음 절 규칙은 유지합니다. 최종 결과에서 아직 확인하지 않은 초안도 채점하고, 이미 확인한 답은 첫 채점 기록을 유지합니다. 탭 종료 후 답안을 보존하지 않습니다.

- 시험 창은 화면 안에서 일정한 높이를 유지합니다. 입력칸은 보이지 않는 별도 측정 요소로 필요한 높이를 구해 줄어들었다 다시 커지는 동작 없이 조절합니다. 키보드로 화면이 줄거나 창 폭이 바뀌면 다시 맞춥니다. 연속 160회 입력 검사에서 390px·1280px 폭의 창·입력칸 시작 위치 변화가 0px였습니다. 실물 휴대폰 검증과는 구분합니다.
- 개역한글 66권은 기존 공개 데이터의 고정 버전을 원문 그대로 사이트에 포함했습니다([출처](scripture/SOURCE.md)). 첫 책 전환에 외부 GitHub 호스트를 거치지 않고, 한 번 읽은 책은 기존 메모리 캐시를 재사용합니다. 다른 역본의 첫 다운로드는 기존 공급 서버와 네트워크 상황의 영향을 받습니다.

- 보이는 높이가 320px 미만이고 폭이 500px 미만이면 시험 창의 반복 제목을 시각적으로 접어 입력·정답 공간을 확보합니다. 대화상자의 접근성 이름과 닫기 버튼은 유지하고, 키보드를 닫거나 화면이 넓어지면 원래 제목이 돌아옵니다. 큰 글씨 자체나 정답 단어의 크기를 줄이는 방식은 사용하지 않습니다. 실제 휴대폰 키보드와 브라우저 모의 검사는 별도로 기록합니다.

진행 중 보이는 높이가 320px 미만이면 제목 줄 전체를 시각적으로 접고 닫기 버튼을 아래 조작부의 44px 닫기 아이콘으로 옮깁니다. 답 확인·범위 변경·닫기를 함께 유지하며 큰 글씨의 세로·가로 화면에도 정답을 스크롤할 공간을 확보합니다. 높이가 돌아오거나 범위 선택·결과 화면으로 바뀌면 닫기 버튼도 원래 자리로 복구됩니다.
