# Bible Reader

PC에서 성경 본문 자체를 가장 편하게 읽기 위한 웹도구입니다.

- 기술 원본: `gsh4124-cyber/page-tools`의 `main / bible-reader/`
- 현재 기술상태: `PROJECT_STATUS.md`
- 상위 운영 원칙: 황제 Vault `직장/바이브코딩/_INDEX.md`
- 운영 주소: `https://bible-reader-1iz.pages.dev/`

## 로컬 작업 위치

로컬 checkout 경로는 환경별로 달라질 수 있으며 Canonical로 고정하지 않습니다. 작업할 때 `page-tools/main`의 실제 checkout 위치를 확인합니다.

과거 `gsh4124-cyber/bible-reader` 독립 repo와 옛 PC 절대경로는 현행 기술 원본으로 사용하지 않습니다.

## 핵심 방향

- PC에서 가장 편하게 읽는 성경
- 개역한글 1961 기본
- 책·장 이동, 검색, 주소 이동, 병렬 비교
- 본문 접근 자체는 유료화하지 않음
- 공개 서비스의 검색·광고·시장 상태는 실제 외부 증거와 운영 Gate를 기준으로 판단

## 타이핑 암기 시험

상단 더보기의 **타이핑 암기 시험**을 열거나 본문에서 여러 절을 선택한 뒤 같은 이름의 버튼을 누릅니다. 선택한 구절, 현재 장의 절 범위, **현재 장·편 전체**, **여러 장·편 묶기**를 지원합니다. 여러 장은 현재 성경책·역본 안에서 시작 장·절과 마지막 장·절을 지정합니다(예: 요한복음 3:16–4:3). 읽기 위치는 바뀌지 않으며, 장·절을 함께 표시해 같은 절 번호가 겹쳐도 답안과 채점이 섞이지 않습니다. 절 수·본문 전체 글자 수 제한 없이 시편 119편 1–176절도 한 번에 시험할 수 있습니다. 본문을 가린 뒤 절마다 직접 입력하고, 띄어쓰기·줄바꿈·문장부호·대소문자는 제외해 글자 단위로 비교합니다. 빠진 글자·다른 글자·추가 입력을 결과에 표시합니다. 본문을 미리 열면 해당 시도는 연습으로 표시하며, 다시 시험은 답안을 비우고 시작합니다. 답안은 저장·전송하지 않습니다.
