# Bible Reader

PC에서 성경 본문 자체를 가장 편하게 읽기 위한 웹도구입니다.

- 기술 원본: `gsh4124-cyber/page-tools`의 `main / bible-reader/`
- 현재 기술상태: `PROJECT_STATUS.md`
- 상위 운영 원칙: 황제 Vault `직장/바이브코딩/_INDEX.md`
- 운영 주소: `https://bible-reader-1iz.pages.dev/`

## 로컬 작업 위치

로컬 checkout 경로는 환경별로 달라질 수 있으며 Canonical로 고정하지 않습니다. 작업할 때 `page-tools/main`의 실제 checkout 위치를 확인합니다.

과거 `gsh4124-cyber/bible-reader` 독립 repo와 옛 PC 절대경로는 현행 기술 원본으로 사용하지 않습니다.

## 핵심 방향

- PC에서 가장 편하게 읽는 성경
- 개역한글 1961 기본
- 책·장 이동, 검색, 주소 이동, 병렬 비교
- 본문 접근 자체는 유료화하지 않음
- 공개 서비스의 검색·광고·시장 상태는 실제 외부 증거와 운영 Gate를 기준으로 판단

## 타이핑 암기 시험

상단 더보기의 **타이핑 암기 시험**을 열거나 본문에서 여러 절을 선택한 뒤 같은 이름의 버튼을 누릅니다. 보기 방식은 **절 하나씩 보기**와 **장 한 번에 보기** 두 가지입니다. 기본은 현재 장 전체를 한 절씩 진행하며, **Enter로 답 확인 → 정답이면 다음 Enter로 다음 절**에 갑니다. 오답이면 수정·재확인할 때까지 같은 절에 머뭅니다. Shift+Enter는 줄바꿈이며, 한글 조합 확정이나 Enter를 길게 누르는 동작은 절을 넘기지 않습니다. 장 보기에서는 현재 장의 절을 함께 입력하고 모두 맞으면 다음 장으로 진행합니다.

접힌 **시험 범위**에서 현재 성경책·역본 안의 시작 장·절과 마지막 장·절을 정해 여러 장도 묶을 수 있습니다(예: 요한복음 3:16–4:3). 마지막 절까지 마치면 첫 답 확인 기준의 결과를 보여줍니다. **틀린 절만 재시험**은 그 시도의 첫 답에서 틀린 절만 빈 답안으로 시작하며, 재시험에서 다시 틀린 절만 반복할 수 있습니다. 모두 맞으면 이 버튼은 사라집니다. **전체 다시 시험**은 처음 선택한 전체 범위로 돌아갑니다. 읽기 위치는 바뀌지 않으며 장·절을 함께 표시해 답안이 섞이지 않습니다. 절 수·본문 전체 글자 수 제한 없이 시편 119편 1–176절도 지원합니다. 띄어쓰기·줄바꿈·문장부호·대소문자는 채점에서 제외하며 빠진 글자·다른 글자·추가 입력을 표시합니다. 답안은 저장·전송하지 않습니다.

시험 중 답 확인·범위 버튼은 아래 조작부에 남고 입력 부분만 스크롤됩니다. 본문은 시작 전 미리보기에서만 확인하며 시험 중 본문 보기와 힌트는 제공하지 않습니다. 장 보기의 입력칸은 작은 높이로 시작해 입력량에 맞춰 늘어나며 Tab으로 다음 절에 갑니다. 입력한 절 수와 진행 막대도 표시합니다. 두두캔의 공개 구절·장 암송 흐름을 직접 비교한 뒤 긴 장의 입력 밀도와 조작부 접근을 개선했습니다([참고 화면](https://dodocan.me/typing)).

시험 화면은 구절·입력칸·필수 조작만 표시합니다. 채점 기준·단축키·답안 처리 안내는 시작 화면의 접힌 도움말에 두며, 진행 중에는 중복 구절 제목과 긴 설명을 반복하지 않습니다. 절 보기의 Enter 동작은 버튼의 ↵ 표시와 접근성 안내로 제공합니다.
