# 페이지형 AdSense 승인 운영기준

실행상태: Supabase `hwangje_ops` / project key `vibecoding`
기술원본: `gsh4124-cyber/page-tools` 최신 `main` + 대상 제품 하위 폴더 + Actions/검증결과

## 목적

페이지형 제품의 광고수익화를 `사이트를 만들고 나서 광고를 붙이는 후처리`로 보지 않고, **실제 서비스가 광고수익 실험을 시작할 조건을 갖췄는지 별도 단계로 검증**한다.

> **AdSense 승인·광고 게재 가능성은 사업 성공이 아니라 수익화 실험을 시작할 자격이다. 승인 뒤에도 실제 유입·사용·재방문·수익·운영부담을 따로 검증한다.**

## 상태 흐름

기본적으로 다음 상태를 구분한다.

> `PRODUCT_QA_PASS`
> → `ADSENSE_ADDRESSABLE`
> → `ADSENSE_READY`
> → `ADSENSE_REVIEW`
> → `ADSENSE_APPROVED`
> → `ADS_LIVE`
> → `SURVIVAL_REVIEW`

- **PRODUCT_QA_PASS** — 핵심 기능이 실제 공개환경에서 작동하고 치명적 결함이 없음
- **ADSENSE_ADDRESSABLE** — 현재 공개주소와 소유구조가 AdSense 사이트 등록·확인에 실제 사용 가능함
- **ADSENSE_READY** — 최신 공식정책과 내부 품질·신뢰·개인정보 조건을 확인해 심사 신청할 가치가 있음
- **ADSENSE_REVIEW** — 실제 사이트 연결·검토 요청 상태
- **ADSENSE_APPROVED** — 계정/사이트의 실제 승인상태가 확인됨
- **ADS_LIVE** — 광고가 실제 공개페이지에서 정상 동작하고 배치·개인정보·사용성 검수를 통과함
- **SURVIVAL_REVIEW** — 실제 유입·수익·사용자 가치·운영비로 유지 여부를 판정함

한 단계의 PASS를 다음 단계 PASS로 자동 승격하지 않는다.

## 공식 기준 우선

AdSense 정책·사이트 주소 허용형식·소유확인·광고코드·동의관리·개인정보·ads.txt 등은 **실제 신청·변경 시점의 Google 공식문서와 현재 계정 UI**를 우선한다.

- 과거 날짜의 숫자·정책·사례를 현재 규칙으로 고정하지 않는다.
- 유튜브·블로그·커뮤니티 성공사례는 참고자료일 뿐 승인 기준의 원본이 아니다.
- 경로형 URL, 호스팅 도메인, 공개접미사 등 주소조건은 추정하지 않고 실제 등록 가능 여부를 확인한다.
- `검토 요청 전송`, `코드 삽입`, `ads.txt 존재`를 각각 승인·광고 라이브와 구분한다.

## `ADSENSE_READY` 내부 체크

### 실제 사용자 가치
- 해결하는 문제가 한 문장으로 설명되는가
- 핵심 기능이 공개 URL에서 정상 작동하는가
- 흔한 대체도구와 비교해 사용할 이유가 있는가
- 목적·사용법·제한·결과를 사용자가 이해할 수 있는가

### 설명 콘텐츠
제품 성격에 필요한 만큼만 제공한다.
- 서비스 목적·대상
- 사용방법
- 기능 설명·활용상황
- FAQ·오해·문제해결
- 제한사항·정확한 기대치
- 필요한 경우 판단 기준·팁

텍스트 양을 채우기 위한 AI 대량문장을 만들지 않는다.

### 신뢰·투명성
현재 서비스에 맞게 필요한 범위에서:
- 서비스 소개
- 개인정보처리방침
- 문의 경로
- 이용약관·면책·출처·권리 고지

를 갖춘다. 문서 내용은 실제 제품 동작과 일치해야 한다.

### 탐색·완성도
- 홈에서 핵심 기능과 정보페이지로 이동 가능
- 죽은 링크·빈 페이지·준비 중 화면 없음
- 주요 모바일/PC 경로가 깨지지 않음
- 검색구조가 실제 URL과 일치
- 광고 예정 위치가 핵심기능·콘텐츠를 방해하지 않음

### 사람 검수
AI가 `승인 준비 완료`라고 판단한 것만으로 신청하지 않는다.

실제 공개 URL을 기준으로 기능·문구·링크·광고 예정 위치를 확인하고 `코드 완료 / 배포 완료 / READY / REVIEW / APPROVED / ADS_LIVE`를 분리한다.

## 광고 라이브 이후

승인 뒤에도 실제 수익성을 별도 검증한다.

최소 관찰 후보:
- 자연유입·직접유입
- 실제 사용·재방문
- 광고가 사용자 경험을 훼손하는지
- 광고수익과 운영비
- 제품 유지·개선에 필요한 황제 직접시간

승인 자체를 제품의 시장성·생존성 PASS로 사용하지 않는다.

제품 생존판정은 `gsh4124-cyber/hwangje-vault`의 `직장/바이브코딩/제품_시장학습_생존판정_운영기준.md`를 따른다.

## 현재상태 소유권

랜덤뽑기·Bible Reader·DEVICE CHECKUP 등 개별 제품의 **현재 AdSense 단계·심사상태·ads.txt·광고코드·현재 blocker·다음 행동**은 이 문서에 저장하지 않는다.

- 운영 projection → Supabase `hwangje_ops`
- 실제 코드·배포·기술상태 → 이 저장소의 해당 제품 폴더
- 실제 AdSense 계정·심사상태 → 현재 계정 UI/공식 실행면

이 문서는 단계 정의와 검증기준만 소유한다.
