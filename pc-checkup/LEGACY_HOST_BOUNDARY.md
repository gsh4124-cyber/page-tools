# LEGACY HOST BOUNDARY — pc-checkup

Updated: 2026-09-28

`gsh4124-cyber/pc-checkup`의 **현재 제품 owner는 DEVICE CHECKUP**이다.

다만 과거 공모전 제출·검증 URL을 깨지 않기 위해 아래 cross-project 자산이 이 저장소에 legacy-host 예외로 남아 있다.

- `refundproof/` 및 관련 Wanted AI Championship QA/workflow
- `proofrail/` 및 관련 핀테크 공모전 pilot QA/workflow
- `finalcheck/` 등 과거 Wanted 후보 자산

## 강제 경계

1. 위 자산은 DEVICE CHECKUP의 제품기능으로 취급하지 않는다.
2. 제출·심사·과거 검증 URL 보존 목적 외에는 신규 cross-project 자산을 이 repo에 추가하지 않는다.
3. RefundProof / ProofRail / 과거 공모전 자산의 전략·현재상태 owner는 황제 Vault `직장/공모전·사업기회`와 Supabase `contest_opportunities`다.
4. DEVICE CHECKUP 기술원본은 이 repo의 DEVICE CHECKUP 코드·Actions·`PROJECT_STATUS.md`다.
5. legacy-host 자산을 제거·이전할 때는 해당 공모전의 제출 URL·심사 의존성이 종료됐는지 먼저 확인한다.
6. 새 공모전이나 새 제품이 필요하면 별도 owner/repo를 우선하고, 이 예외를 관성적으로 재사용하지 않는다.

> **LEGACY HOST ≠ SHARED OWNER.**
