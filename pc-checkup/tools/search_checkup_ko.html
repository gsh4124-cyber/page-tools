PC 기기 점검 결과를 읽는 방법

각 항목의 ‘정상’·‘이상’ 표시는 직접 확인한 결과를 남기는 기록입니다. 자동으로 모든 부품의 상태를 판정하거나 제품의 무결함을 인증하는 결과가 아닙니다.

  1. 검사할 PC에서 이 페이지를 열고 연결된 키보드·마우스를 확인합니다.
  2. 화면과 스피커는 눈과 귀로 확인하고, 마이크·카메라는 선택한 입력 장치와 접근 권한을 확인합니다.
  3. 검사를 마친 항목만 표시하세요. 확인하지 못한 항목은 정상으로 기록하지 않습니다.
  4. 이상이 반복되면 다른 브라우저나 연결 장치에서도 확인하고, 결과 요약과 발생 조건을 함께 남깁니다.

브라우저 검사로 SSD 수명, 메모리 전체 안정성, CPU·GPU의 장시간 부하 상태를 확정할 수는 없습니다. 그런 증상은 제조사의 진단 도구나 점검 서비스를 함께 확인하세요.

중고 노트북 구매 전 기본 점검 순서

거래 현장에서 실제 구매할 노트북으로 이 페이지를 여세요. 외장 키보드·헤드셋을 연결했다면 내장 장치와 구별해서 확인해야 합니다. 정상 표시는 직접 확인한 항목에만 남기세요.

  1. 키보드 입력 테스트에서 문자·방향키·좌우 Shift를 직접 눌러 반응을 확인합니다. Fn처럼 브라우저에 전달되지 않는 키는 이 검사만으로 판단하지 않습니다.
  2. 화면 검사에서 단색 화면을 띄워 밝은 점·어두운 점·색이 다른 부분을 살펴봅니다. 화면 가장자리와 밝기도 직접 확인하세요.
  3. 스피커 좌우 출력을 듣고, 마이크 입력과 웹캠 영상은 선택된 장치와 브라우저 권한을 확인합니다.
  4. 검사 뒤 결과 요약을 복사해 검사 날짜, 사용한 브라우저, 반복되는 증상과 함께 기록합니다. ‘미확인’은 정상으로 바꾸지 않습니다.

브라우저 검사 밖에서 별도로 확인할 항목

힌지·외관·충전단자·충전기 연결·배터리 상태·저장장치 상태·제품 정보 일치는 판매자와 실제 기기에서 따로 확인하세요. 이 사이트의 결과는 거래 안전이나 제품 전체 상태를 보증하는 인증서가 아닙니다.

휴대폰을 검사하려면 휴대폰 기기 점검으로 이동하세요.
