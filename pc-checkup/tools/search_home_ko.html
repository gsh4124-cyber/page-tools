기기 점검, 무엇부터 확인하면 되나요?

새 PC·노트북·휴대폰을 받았거나 중고 거래 전에 기본 입출력 상태를 확인할 때 사용할 수 있습니다. 설치 없이 브라우저에서 검사를 열고, 화면과 소리처럼 직접 판단해야 하는 항목은 눈과 귀로 확인하세요.

PC·노트북 점검 순서

  1. 키보드 점검으로 자주 쓰는 키와 동시 입력을 확인합니다.
  2. 마우스 점검에서 좌우 클릭, 휠, 이동을 확인합니다.
  3. 화면·불량화소 검사에서 단색 화면을 직접 살펴봅니다.
  4. 스피커, 마이크, 웹캠을 차례로 확인합니다.

휴대폰 점검 순서

  1. 터치가 화면의 여러 위치에서 반응하는지 확인합니다.
  2. 화면의 밝은 점, 어두운 점, 색이 다른 부분을 살펴봅니다.
  3. 카메라 영상과 마이크 입력, 스피커 소리를 확인합니다.
  4. 지원되는 브라우저에서는 진동과 화면 회전도 확인합니다.

기기 점검 전 알아둘 점

무료로 사용할 수 있나요?

브라우저에서 제공하는 기기 점검은 무료이며 설치나 회원가입이 필요하지 않습니다. 실제 점검할 기기에서 이 사이트를 열어 사용하세요.

카메라와 마이크 권한이 필요한가요?

카메라와 마이크 검사는 브라우저의 접근 권한을 허용해야 작동합니다. 권한이 거부된 상태라면 장치 고장으로 판단하지 말고 선택한 입력 장치와 브라우저 설정을 먼저 확인하세요.

정상이면 모든 하드웨어에 문제가 없다는 뜻인가요?

아닙니다. 이 검사는 브라우저에서 확인할 수 있는 입력·영상·소리와 화면의 기본 동작을 살펴봅니다. 배터리 수명, 저장장치 상태, 내부 부품이나 장시간 사용 중 발생하는 문제까지 판정하지는 못합니다.

이상이 보이면 어떻게 하나요?

다른 브라우저나 연결 장치로 같은 검사를 해보고 증상이 반복되는지 확인하세요. 반복되는 증상과 확인 조건을 정리하면 구매처나 제조사에 문의할 때 참고할 수 있습니다.
