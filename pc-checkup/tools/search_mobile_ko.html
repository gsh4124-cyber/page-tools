기기 점검 홈 / 휴대폰 점검

휴대폰 기기 점검을 시작하기 전에

점검할 휴대폰에서 직접 이 페이지를 여세요. PC에서 열면 PC에 연결된 카메라·마이크를 확인하게 되며 휴대폰의 상태를 대신 검사할 수 없습니다.

  1. 화면 여러 곳을 직접 터치하고, 단색 화면에서 밝거나 어두운 점을 살펴봅니다.
  2. 카메라·마이크 검사를 할 때 브라우저 권한과 선택한 장치를 확인합니다. 권한 거부만으로 기기 고장을 판단하지 않습니다.
  3. 스피커 출력이 들리지 않으면 기기 음량과 블루투스 이어폰 연결도 확인합니다.
  4. 진동·화면 회전은 운영체제와 브라우저의 지원 여부에 따라 달라집니다. 지원되지 않는 항목은 고장으로 단정하지 않습니다.

이 페이지는 배터리의 남은 수명, 침수 여부, 내부 부품의 상태를 인증하지 않습니다. 증상이 반복되면 검사 조건과 결과 요약을 남겨 제조사에 문의할 때 참고하세요.

컴퓨터를 검사하려면 PC·노트북 기기 점검으로 이동하세요.
