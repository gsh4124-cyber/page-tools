온라인 사다리타기

참가자와 결과를 서로 연결하는 사다리입니다. 한 명을 뽑을 때와 각자 다른 역할을 배정할 때의 설정 차이를 예시로 확인하세요.

사다리는 언제 쓰면 좋을까요?

여러 사람이 각자 출발점을 고르고 연결된 결과를 확인할 때 적합합니다. 당번 한 명을 뽑는 일과 발표·정리·기록 같은 역할을 각각 배정하는 일은 결과 설정이 다릅니다. 먼저 필요한 결과의 개수를 정하면 입력을 다시 고칠 일이 줄어듭니다.

4명에게 역할 4개를 배정하는 예시

  1. 사다리를 열고 이름 모드를 선택합니다. 가람·나래·다온·라온을 각각 다른 줄에 입력합니다.
  2. 뽑을 인원을 4명으로 맞추고 결과에서 직접 입력을 선택합니다.
  3. 결과를 발표, 기록, 자료 정리, 시간 확인 순서로 한 줄에 하나씩 적습니다.
  4. 사다리 만들기를 누른 뒤 위 참가자 버튼을 눌러 경로를 따라갑니다. 전체 결과와 각 이름의 연결을 확인합니다.

직접 입력 결과는 정한 뽑을 인원 수만큼 사용됩니다. 네 명 모두에게 역할이 필요하면 인원과 결과를 각각 네 개로 맞추세요. 두 명만 당번으로 뽑는다면 결과를 당첨으로 두고 뽑을 인원을 2명으로 정하는 편이 간단합니다.

화면과 입력을 확인하는 순서

동명이인이 있으면 가람 A·가람 B처럼 구별하세요. 이름이 같아도 서로 다른 입력 줄이면 별도 참가자가 됩니다. 인원이 많은 사다리는 가로로 이동하며 확인할 수 있으므로, 모임 전체에 보여 줄 때는 글자가 읽히는지 먼저 확인하세요.

당첨자만 보다가 전체 연결이 궁금하면 전체 결과 보기를 사용하세요. 진행 중 바로 결과 보기는 이미 만든 사다리의 결과를 펼치는 기능입니다. 결과가 마음에 들지 않아 새로 시작하는 것과 구별해 사용하세요.

자주 묻는 질문

이전 당번을 빼고 이어서 뽑으려면?
당첨 결과로 진행한 뒤 결과 화면의 당첨자 제외하고 다시 뽑기를 사용합니다. 전체에서 다시 뽑기는 이전 당첨자를 다시 포함합니다.
운영자가 특정 사람의 결과를 지정하는 기능이 있나요?
공개된 추첨 화면에는 특정 참가자의 결과를 지정하는 설정이 없습니다. 참가 명단과 결과 항목은 진행자가 입력하므로 시작 전에 함께 확인하세요.
