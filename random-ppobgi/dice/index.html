온라인 주사위 굴리기

보드게임을 하는데 주사위가 사라졌을 때, 화면에서 바로 굴릴 수 있는 주사위입니다. 1부터 6까지 같은 확률로 나와요.

주사위 굴리기 바로 시작 →

사용 방법

  1. 게임 도구에서 주사위를 엽니다.
  2. 굴리기를 누릅니다.
  3. 나온 눈이 크게 표시됩니다.

이럴 때 쓰세요

  • 보드게임 주사위 대용
  • 수학 시간 확률 실험
  • 술래·차례 정하기, 간단한 내기

자주 묻는 질문

정말 무작위인가요?
브라우저의 난수 기능으로 1~6이 같은 확률로 나옵니다.
휴대폰에서도 되나요?
네. 휴대폰 화면에 맞게 표시됩니다.
앱 설치가 필요한가요?
아니요. 브라우저에서 바로 사용합니다.
