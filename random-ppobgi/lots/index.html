랜덤뽑기 사용 가이드

온라인 제비뽑기

번호로 구분한 제비를 하나씩 열어 결과를 확인합니다. 이름 명단을 입력하는 추첨과 달리 제비의 수와 당첨 결과를 설정합니다.

온라인 제비뽑기 열기 →

8장의 제비에서 당첨 2개 만들기

  1. 제비뽑기를 열고 제비 수를 8장으로 정합니다. 이 숫자가 제비의 개수입니다.
  2. 당첨 제비 수를 2장으로 두고 결과를 당첨으로 선택합니다.
  3. 제비 섞기를 누르면 번호로 구분된 제비가 나옵니다. 참가자마다 열 제비 번호를 먼저 정합니다.
  4. 제비를 하나씩 눌러 결과를 확인합니다. 모두 확인할 때는 바로 결과 보기를 사용할 수 있습니다.

제비 번호는 제비를 구분하기 위한 표시입니다. 이름 탭이나 별도의 이름 목록을 받지 않습니다. 누가 어떤 번호를 골랐는지 알아야 한다면 시작 전에 참가자들과 번호를 연결해 기록하세요. 이름 자체를 당첨 결과에 표시하고 싶다면 룰렛이나 사다리가 더 적합합니다.

역할이나 문구를 직접 넣는 경우

결과를 직접 입력으로 바꾸면 여러 문구를 사용할 수 있습니다. 네 제비 모두에 다른 역할을 붙이고 싶다면 제비 수와 당첨 제비 수를 모두 4장으로 맞추고 발표·기록·정리·시간 확인을 각각 다른 줄에 적으세요.

직접 입력 결과는 당첨 제비 수만큼만 사용됩니다. 제비 수보다 적은 결과를 배정하면 나머지 제비는 꽝으로 표시됩니다. 결과 문구를 더 많이 적었다면 실제 사용되는 개수를 시작 전에 확인하세요.

진행할 때 헷갈리기 쉬운 점

열린 제비를 다시 누르는 일과 새로 섞는 일은 다릅니다. 참가자 전원이 결과를 확인하기 전에는 새 추첨을 시작하지 않는 편이 좋습니다. 바로 결과 보기는 현재 제비의 결과를 한 번에 펼칩니다.

같은 결과 문구가 여러 개 있어도 각 제비는 서로 구분됩니다. 두 장 모두 당첨이라면 당첨이라는 문구가 같아도 서로 다른 제비에 배정된 결과입니다.

자주 묻는 질문

제비에 참가자 이름을 입력하나요?
이 도구는 번호로 제비를 구분합니다. 참가자 이름을 받지 않으며 원하는 당첨 인원이나 결과 문구를 설정합니다.
이전 당첨 제비를 자동으로 제외할 수 있나요?
제비뽑기는 당첨자 제외 재추첨을 제공하지 않습니다. 같은 참가자를 다시 뽑지 않으려면 이름을 입력하는 룰렛이나 사다리의 당첨 모드를 사용하세요.
