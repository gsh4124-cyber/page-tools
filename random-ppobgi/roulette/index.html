랜덤 룰렛 돌리기

이름이나 메뉴 가운데 한 항목을 고르는 룰렛입니다. 같은 글자를 여러 번 입력했을 때의 확률과 반복 당첨을 구별해서 읽어보세요.

한 항목을 고르는 설정

  1. 룰렛을 열고 이름 모드를 선택합니다.
  2. 후보를 한 줄에 하나씩 입력합니다. 예를 들어 비빔밥, 국수, 덮밥, 샐러드를 각각 한 번씩 적습니다.
  3. 입력 목록을 확인하고 룰렛 돌리기를 누릅니다. 멈춘 뒤 표시되는 최종 결과를 확인합니다.

룰렛은 한 번에 한 항목을 고릅니다. 전원의 순서가 필요하면 순서 정하기, 여러 팀이 필요하면 팀 나누기를 선택하세요. 번호 모드에서는 총 인원에 맞춰 1번부터 후보가 만들어집니다.

같은 항목을 두 번 넣으면 어떻게 될까요?

입력한 네 줄산다 확률안 산다 확률
산다 / 안 산다 / 산다 / 안 산다2/4 = 50%2/4 = 50%
산다 / 산다 / 산다 / 안 산다3/4 = 75%1/4 = 25%

같은 글자를 여러 번 적어도 입력 줄마다 별도 칸으로 남습니다. 모든 선택지의 비중을 같게 하려면 각 후보를 한 번씩 입력하세요. 색은 칸을 구분하는 표시이며, 같은 문구가 있는 칸의 개수와는 별개입니다.

세 번 같은 결과가 나와도 이상한가요?

산다와 안 산다가 각각 두 칸인 예시에서 매번 전체 후보를 다시 사용하면, 산다가 세 번 나올 확률은 1/2 × 1/2 × 1/2 = 1/8입니다. 산다 또는 안 산다 중 어느 쪽이든 세 번 연속 같은 문구일 확률은 2/8 = 25%입니다.

이 계산은 같은 문구와 같은 개별 칸을 구별합니다. 네 칸 중 미리 지정한 한 칸이 세 번 나올 확률은 1/64입니다. 적은 횟수의 반복만으로 무작위 선택의 이상 유무를 판정할 수는 없습니다. 경우별 계산과 기록 방법을 함께 확인하세요.

자주 묻는 질문

같은 사람을 다시 뽑고 싶지 않다면?
결과 화면에서 당첨자 제외하고 다시 뽑기를 선택하세요. 전체에서 다시 뽑기는 처음 후보 전체를 다시 사용합니다.
도중에 바로 결과 보기를 누르면 다시 추첨하나요?
진행 중인 룰렛에서 바로 결과 보기는 그 실행에서 정해진 선택을 보여줍니다. 새로운 후보를 다시 고르는 재추첨 버튼과 다릅니다.
