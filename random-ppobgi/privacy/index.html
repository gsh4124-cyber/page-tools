개인정보처리방침

시행일: 2026년 8월 24일

입력 내용

현재 랜덤뽑기는 회원가입 기능이 없으며, 사용자가 입력한 이름·번호·직접 입력 결과를 서버로 전송하거나 서버에 저장하지 않습니다. 이 내용은 현재 공개된 서비스 코드의 동작을 기준으로 하며, 입력값은 사용 중인 브라우저 안에서 추첨을 위해 처리됩니다.

익명 이용 통계

서비스 개선을 위해 게임 시작·완료·재추첨·당첨자 제외 재추첨 횟수를 익명으로 집계할 수 있습니다. 이때 게임 종류, 입력 방식, 참가 인원 구간, 결과 방식처럼 개인을 식별하지 않는 범주 정보만 전송합니다. 사용자가 입력한 이름·번호·직접 입력 결과·당첨 내용은 전송하지 않으며, 별도 사용자 ID·광고 ID·쿠키를 이용한 개인별 행동 추적도 하지 않습니다. 개별 행동 원본 대신 날짜별 합계만 저장합니다.

Cloudflare

서비스 호스팅, 익명 이용 통계 처리 및 운영 상태 확인에 Cloudflare Pages, Pages Functions, D1과 Web Analytics가 사용될 수 있습니다. Cloudflare의 네트워크 처리에는 Cloudflare 정책이 적용됩니다. 서비스 코드에는 Google Analytics와 광고 스크립트를 사용하지 않습니다.

외부 링크

문의용 GitHub Issues 등 외부 사이트로 이동하면 해당 서비스의 개인정보처리방침이 적용됩니다.

변경

향후 광고, 계정, 서버 저장 기능이 도입되면 실제 처리 내용에 맞춰 이 방침을 변경하고 시행일을 표시합니다.
