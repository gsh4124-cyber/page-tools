랜덤뽑기 사용 가이드

반복 당첨과 중복 입력, 확률을 읽는 법

같은 문구와 같은 개별 칸은 다른 사건입니다. 룰렛 네 칸, 중복 문구, 당첨자 제외 재추첨의 차이를 실제 입력 예시로 비교합니다.

먼저 무엇이 반복됐는지 구별하세요

룰렛에 산다, 안 산다, 산다, 안 산다를 입력하면 글자는 두 종류지만 칸은 네 개입니다. 산다가 반복되는 일과 특정한 산다 칸 하나가 반복되는 일은 확률이 다릅니다. 색은 칸을 알아보기 위한 구분이므로 문구와 칸 번호를 함께 기록하면 혼동을 줄일 수 있습니다.

네 칸을 매번 전체에서 다시 뽑는 예시

확인하려는 사건계산이론 확률
미리 지정한 한 칸이 세 번(1/4)³1/64 = 1.5625%
어느 칸이든 같은 개별 칸이 세 번4 × (1/4)³1/16 = 6.25%
산다라는 문구가 세 번(2/4)³1/8 = 12.5%
산다 또는 안 산다 중 같은 문구가 세 번2 × (1/2)³1/4 = 25%

이 표는 동일 크기의 네 칸에서 독립적으로 하나를 선택하고, 매번 전체 후보를 다시 사용하는 예시입니다. 입력한 후보를 바꾸거나 당첨자를 제외한 경우에는 그대로 적용할 수 없습니다.

한 번에 칸 하나를 고르는 과정에서는 각 입력 항목을 구별합니다. 같은 문구를 두 번 적으면 그 문구의 비중은 두 칸을 합해 읽어야 합니다.

전체 재추첨과 당첨자 제외는 다릅니다

후보가 네 명일 때 처음 한 명을 고르면 각 참가자의 확률은 1/4입니다. 전체에서 다시 뽑기를 선택하면 이전 당첨자도 다시 후보가 됩니다. 당첨자 제외하고 다시 뽑기는 그 사람을 빼고 남은 세 명으로 진행하므로 제외된 사람은 다음 추첨에서 나오지 않고, 남은 각 사람의 비중은 1/3이 됩니다.

새 명단이나 다른 뽑기 방식으로 바꾸면 이전 회차의 제외 상태를 그대로 가정하지 마세요. 결과 화면에 표시되는 남은 후보를 확인하고, 명단 변경이 있을 때는 참가자들에게 기준을 다시 알리세요.

입력 전 확인할 네 가지

  1. 선택지마다 같은 비중을 주려면 각 항목을 한 번씩 적습니다.
  2. 같은 이름의 다른 사람은 A·B 또는 출석번호를 붙여 구별합니다.
  3. 한 사람을 계속 제외할지 전체에서 새로 뽑을지 미리 정합니다.
  4. 바로 결과 보기는 현재 실행을 펼치는 기능인지, 다시 뽑기는 새 실행인지 구분합니다.

결과가 이상하게 느껴질 때 남길 기록

입력한 후보, 게임 이름, 전체 재추첨인지 제외 재추첨인지, 실행 횟수와 표시 결과를 같은 기준으로 적어보세요. 확인하려는 사건이 특정 칸인지 같은 문구인지도 구별합니다. 적은 횟수의 반복만으로 난수가 고장 났다고 단정하거나 반대로 정상이라고 보증할 수는 없습니다.

화면의 당첨 표시와 최종 결과가 다르거나, 제외한 참가자가 같은 제외 회차에서 다시 나온다면 재현 가능한 오류일 수 있습니다. 문의 안내의 기기·브라우저·진행 순서를 함께 남겨주세요. 이름 대신 가상 명단으로도 같은 문제가 생기는지 확인하면 개인정보를 공개하지 않고 설명할 수 있습니다.

도구가 제공하는 범위

브라우저 난수 기능을 이용하는 편의 도구이며 제3자가 참관한 추첨 인증이나 변경 불가능한 회차 기록을 제공하지 않습니다. 필요한 후보와 진행 규칙을 참가자들이 함께 확인한 뒤 사용하세요. 룰렛 설정 안내와 제비의 결과 배정 안내에서 입력 방식의 차이도 볼 수 있습니다.
