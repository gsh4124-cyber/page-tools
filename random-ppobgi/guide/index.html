GUIDE

랜덤 팀 나누기와 이름·번호 뽑기 사용법

이름이나 번호 중 입력 방식을 고르고, 필요한 당첨 인원과 게임을 선택하면 추첨을 시작할 수 있습니다. 아래 예시로 입력 방법과 중복 당첨을 제외하는 방법을 확인하세요.

이름 추첨번호 추첨당첨자 제외팀 나누기발표 순서게임 선택자주 묻는 질문

더 자세히 읽기

  • 같은 결과가 반복될 때: 칸·문구·중복 입력과 확률
  • 수업 준비 예시: 발표·모둠·좌석에 맞는 도구 고르기

이름을 입력해 랜덤뽑기

  1. 랜덤뽑기에서 ‘이름’을 선택합니다.
  2. 참가자를 한 줄에 한 명씩 입력합니다. 쉼표로도 구분할 수 있습니다. 제비뽑기는 이름 입력 없이 제비 수와 결과를 정합니다.
  3. 게임에서 지원하는 인원과 결과 방식을 확인하고 ‘사다리 만들기’나 ‘게임 준비’ 등 선택한 방식의 준비 버튼을 누릅니다.

예를 들어 ‘민수’, ‘지영’, ‘수진’을 각각 다른 줄에 적으면 세 참가자가 됩니다. 동명이인은 ‘민수 A’, ‘민수 B’처럼 구별해서 적으세요. 같은 이름을 여러 번 넣으면 각각 별도 참가자로 처리되므로, 한 사람을 한 번만 넣으려면 입력 목록을 먼저 확인해야 합니다.

번호로 랜덤뽑기

명단을 입력하지 않을 때는 ‘번호’를 선택하고 총 인원을 정하세요. 총 인원이 8명이면 참가 번호는 1~8로 만들어집니다. 수업의 발표자, 모임의 순서처럼 미리 정한 번호와 연결해 사용할 수 있습니다.

중복 당첨을 제외하고 다시 뽑기

제비뽑기를 제외한 당첨 결과 모드에서는 결과 화면의 ‘당첨자 제외하고 다시 뽑기’를 누르면 이미 뽑힌 참가자를 빼고 다음 추첨을 진행합니다. ‘전체에서 다시 뽑기’는 처음 참가자 전체를 대상으로 하므로 이전 당첨자가 다시 뽑힐 수 있습니다. 다음 추첨 전에 남은 참가자와 뽑을 인원을 확인하세요.

모임 이름이나 회차를 결과와 함께 기록하면 어느 명단에서 뽑은 결과인지 구분하기 쉽습니다. 명단을 바꿨다면 새 참가자 목록을 확인하고 다시 시작하세요.

상황에 맞는 뽑기 방식 고르기

사다리
참가자와 결과가 연결되는 경로를 함께 볼 때 사용합니다.
룰렛
한 명이나 한 항목을 빠르게 선택할 때 사용합니다.
제비
참가자가 제비를 하나씩 열어 결과를 확인할 때 사용합니다.
핀볼·경주
움직이는 과정을 보며 한 명의 당첨자를 확인할 때 사용합니다.
캡슐·슬롯
짧은 연출로 선택 결과를 보여줄 때 사용합니다.
폭탄
기기를 차례로 전달하며 무작위 순간에 걸리는 참가자를 정할 때 사용합니다.

수업 발표자를 중복 없이 뽑는 예시

출석번호가 1~24번인 수업이라면 ‘룰렛’과 ‘번호’를 선택한 뒤 총 인원을 24명으로 설정합니다. 한 명을 뽑은 뒤에는 ‘당첨자 제외하고 다시 뽑기’를 선택해 이미 발표한 번호를 다음 추첨에서 제외하세요. 결석자가 있다면 ‘이름’ 모드에서 실제 참여자만 입력하는 편이 정확합니다.

랜덤 팀 나누기: 12명을 3팀으로 편성하기

모든 참가자를 몇 개의 조로 나누고 싶다면 ‘팀 나누기’를 사용하세요. 한 명의 당첨자를 고르는 추첨과 달리 참가자 전원이 한 팀씩 배정됩니다.

  1. 팀 나누기 도구를 열고 실제 참여자만 한 줄에 한 명씩 입력합니다.
  2. ‘팀 수’에서 3을 선택합니다. 팀 수는 한 팀의 인원이 아니라 만들 팀의 개수입니다.
  3. ‘팀 나누기’를 누른 뒤 각 팀에 이름이 한 번씩 포함됐는지 확인합니다.

연습할 때는 아래의 가상 명단을 복사해 넣어보세요. 12명을 3팀으로 나누면 팀마다 4명입니다.

발표 순서 정하기: 전원의 차례를 한 번에 만들기

12명 모두 발표할 예정이라면 한 명씩 반복해서 뽑기보다 ‘순서 정하기’에서 전체 차례를 만드는 편이 간단합니다. 명단을 입력하고 ‘순서 섞기’를 누르면 1번부터 전원의 차례를 볼 수 있습니다.

  1. 순서 정하기 도구에 참가자를 한 줄에 한 명씩 입력합니다.
  2. 동명이인은 ‘민수 A’, ‘민수 B’처럼 구별합니다. 중복 입력은 별도 참가자로 남으니 미리 확인하세요.
  3. ‘순서 섞기’를 한 번 누르고 첫 결과를 참가자들과 확인합니다. 합의한 순서를 보관하려면 결과 화면을 캡처하거나 따로 기록하세요.

빈 명단으로 시작하면 도구의 기본 예시인 1~8번이 나옵니다. 실제 수업에서는 참가자 수에 맞는 명단을 직접 넣으세요. ‘다시 섞기’는 아직 발표하지 않은 사람만 고르는 기능이 아니라 명단 전체의 순서를 새로 만듭니다.

어떤 도구를 골라야 하나요?

오늘 발표할 한 명만 뽑으려면?
이름·번호 뽑기를 사용합니다. 다음 차례에는 결과 화면에서 ‘당첨자 제외하고 다시 뽑기’를 선택하세요.
전원을 여러 모둠으로 나누려면?
팀 나누기에 전체 명단과 팀 수를 넣습니다. 이미 나눈 팀의 일부를 고정하는 기능은 제공하지 않습니다.
전원의 차례가 필요하면?
순서 정하기에서 명단 전체를 섞습니다. 같은 이름을 두 번 적으면 순서에도 두 번 나오므로 입력을 확인하세요.
남은 인원이 팀 수보다 적으면?
실제 참가자보다 많은 팀을 만들지 않습니다. 결과의 팀 수와 명단을 다시 확인한 뒤 사용하세요.
추첨 결과를 공정한 거래나 경품 인증에 써도 되나요?
일상적인 수업·모임을 돕는 도구입니다. 제3자의 참관이나 변조 방지를 보증하는 추첨 인증서가 아니며, 공식 행사의 규칙과 기록은 별도로 마련해야 합니다.

입력한 이름은 어디에 보관되나요?

입력한 이름과 추첨 결과는 현재 브라우저에서 처리됩니다. 공유 화면이나 녹화에 명단이 표시될 수 있으므로 공개 전에 내용을 확인하세요. 개인정보처리방침에서 저장·집계 범위를 확인할 수 있습니다.
