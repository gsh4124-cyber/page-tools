랜덤뽑기 사용 가이드

수업 발표·모둠·좌석을 준비하는 진행 예시

결석자와 동명이인을 정리한 뒤 발표자 한 명, 전원 순서, 모둠, 좌석 중 필요한 도구를 고릅니다. 12명 수업을 가정해 준비와 진행을 따라가 보세요.

먼저 오늘의 목적을 하나 정하세요

필요한 결과맞는 도구확인할 점
오늘 발표자 한 명룰렛 또는 사다리다음 차례에 이전 발표자를 제외할지
12명 전원의 발표 차례순서 정하기명단에 각 사람이 한 번씩 있는지
12명을 3모둠으로팀 나누기팀 수 3과 팀당 인원 4를 구별
교실의 실제 좌석표자리 바꾸기줄·칸, 빈 좌석, 고정 좌석의 조건

가상 명단으로 먼저 준비하기

다음 명단은 연습용 가상 이름입니다. 실제 수업에서는 결석자를 빼고 참여할 사람만 입력하세요. 동명이인이 있으면 나래 A·나래 B처럼 학생들이 알아볼 수 있는 구별을 붙입니다.

이름 대신 번호를 쓰려면 번호와 실제 학생을 연결한 기준을 먼저 정하세요. 총 인원만 넣는 번호 모드는 1번부터 연속으로 만들어지므로, 중간 번호의 결석자를 자동으로 건너뛰지 않습니다. 이런 경우 이름 모드에 실제 참여 번호만 한 줄씩 적을 수 있습니다.

발표자 한 명을 뽑고 다음 차례로 넘어가기

  1. 룰렛의 이름 모드에 참여자만 입력합니다.
  2. 룰렛을 한 번 돌리고 결과를 함께 확인합니다.
  3. 이미 발표한 학생을 다시 뽑지 않기로 했다면 당첨자 제외하고 다시 뽑기를 선택합니다.
  4. 다음 실행 전에 남은 후보가 맞는지 확인합니다.

전원이 발표할 예정이면 순서 정하기에서 전체 차례를 한 번에 정하는 편이 간단합니다. 발표 중간에 명단 전체를 다시 섞으면 끝난 사람도 다시 포함됩니다.

12명을 3모둠으로, 10명을 3모둠으로

팀 나누기에 12명을 넣고 팀 수를 3으로 정하면 각 모둠이 4명씩 됩니다. 두 명이 결석해 10명이면 모둠 인원은 4명·3명·3명입니다. 인원 차이를 줄이는 기능이며 학습 수준이나 역할을 기준으로 편성하는 기능은 아닙니다.

모둠 구성에 꼭 필요한 조건이 있다면 진행자가 결과를 보고 조정하세요. 특정 학생의 팀을 고정하거나 특정 조합을 반드시 분리하는 설정은 제공하지 않습니다. 모둠 안에서 발표·기록·정리 같은 역할을 나누려면 사다리의 직접 입력 결과를 별도로 사용할 수 있습니다.

좌석표는 자리 바꾸기에서 만들기

자리 바꾸기는 발표 순서 도구와 달리 줄과 칸, 1인·2인 짝·3인 모둠 책상을 정하는 좌석표 도구입니다. 먼저 실제 교실의 좌석 수를 맞추고 쓰지 않는 곳은 빈 자리로 지정하세요.

배치 후 자리를 누르면 고정할 수 있습니다. 지난번 자리 피하기는 겹침을 줄이는 방식이며, 모든 조건에서 전원이 반드시 다른 자리로 간다는 보장은 아닙니다. 교사 시점과 학생 시점의 방향도 함께 확인한 뒤 복사·인쇄 기능을 사용하세요.

화면을 보여주기 전 마지막 확인

  1. 명단에서 누락과 중복을 확인합니다.
  2. 당첨자 수·팀 수·좌석 수가 오늘의 목적에 맞는지 확인합니다.
  3. 다시 뽑기나 다시 섞기를 허용할 조건을 미리 합의합니다.
  4. 공용 화면에는 필요한 이름이나 번호만 보여 주고, 공유·캡처 전 표시 내용을 확인합니다.

다음 수업에 같은 설정을 쓰려면

뽑기 게임에서 설정 세트를 저장하면 참가자와 인원, 선택한 방식 등의 설정을 이 브라우저에서 다시 불러올 수 있습니다. 설정을 불러오는 것만으로 추첨이 시작되지는 않습니다. 이전 회차의 제외자를 그대로 이어 붙이는 것도 아니므로 현재 명단과 남은 후보를 확인하세요.

브라우저 사이트 데이터를 지우거나 다른 기기로 옮기면 같은 저장 내용을 자동으로 가져오지 않습니다. 각 도구의 저장 범위는 개인정보처리방침에서 확인할 수 있습니다.
